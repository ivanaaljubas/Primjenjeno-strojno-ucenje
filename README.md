# Primijenjeno strojno učenje – Laboratorijske vježbe

Ovaj repozitorij sadrži skup laboratorijskih vježbi iz kolegija **Primijenjeno strojno učenje**. Kroz ove vježbe stekla sam praktično znanje u obradi podataka, treniranju modela strojnog učenja i evaluaciji rezultata.

## Stečene vještine
- Rad s bibliotekama **NumPy**, **Pandas**...
- Učitavanje, analiza i vizualizacija podataka
- Obrada i priprema podataka (normalizacija, standardizacija, kodiranje kategorijskih podataka)
- Razdvajanje podataka na trening i test skupove
- Primjena različitih algoritama:
  - Klasifikacija: KNN, logistička regresija, SVM, stablo odluke
  - Regresija: linearna regresija, polinomna regresija
  - Grupiranje (Clustering): K-means
- Evaluacija modela: točnost, matrica zabune, ROC/AUC, 
- Osnovno korištenje neuronskih mreža
